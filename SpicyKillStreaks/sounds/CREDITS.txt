Where the sounds come from

The announcer recordings are not covered by the addon's GNU GPL v2 licence. They remain the
property of their owners and are included only as they were in dG KillShot. If you hold the
rights to one of them and want it removed, open an issue on GitHub (zednx/spicy-kill-streaks).

Voice packs: male (this folder), female\, sexy\, baby\, humiliation\
  Came with dG KillShot by Lance Inman (WowAce/CurseForge project "dgks"). dG KillShot describes
  them as Unreal Tournament, DotA and Mortal Kombat sounds. The male and female packs are
  Unreal Tournament style announcers (Unreal Tournament is (c) Epic Games). The original
  source of "sexy" and "baby" is not stated anywhere we could find.

headshot.ogg, firstblood.ogg, pancake.ogg
  Added for Spicy Kill Streaks 0.6.0 from files supplied by the author. Source: to be confirmed.

gank.ogg
  Added for Spicy Kill Streaks 1.1.0 from a file supplied by the author. The file's metadata
  names sound designer Jamey Scott (2003). Source: to be confirmed.

secret15.ogg (male pack), secret25.ogg, secret40.ogg, secretgank.ogg
  Added for Spicy Kill Streaks 1.6.0 from files supplied by the author: announcer lines
  (secret25.ogg's and secretgank.ogg's metadata names sound designer Jamey Scott, 2003).
  Source: to be confirmed. (What they say is a surprise.)

secret30.ogg
  Added for Spicy Kill Streaks 1.6.0 from a file supplied by the author: a line from the GLaDOS
  announcer pack for Dota 2 ((c) Valve Corporation). (What it says is a surprise.)

secret20.ogg
  Added for Spicy Kill Streaks 0.7.0 from a file supplied by the author. An Unreal Tournament
  2004 announcer line ((c) Epic Games). (What it says is a surprise.)

flag_blue_*.ogg, flag_red_*.ogg (taken, dropped, returned, scores)
  Added for Spicy Kill Streaks 1.7.0 from files supplied by the author: Unreal Tournament style
  capture-the-flag announcer lines. Source: to be confirmed.

zealot\
  Added for Spicy Kill Streaks 1.9.0 from files supplied by the author: taunts from Unreal
  Tournament 3 ((c) Epic Games), pitched down two semitones and evened out in loudness.

biggame.ogg
  Added for Spicy Kill Streaks 1.9.0 from a file supplied by the author: an announcer line.
  Source: to be confirmed.

grudge.ogg, nemesis.ogg
  Added for Spicy Kill Streaks 1.9.0 from files supplied by the author: Unreal Tournament 3
  reward announcer lines ((c) Epic Games), the same announcer as retribution.ogg. (What they say
  is a surprise.)

retribution.ogg
  Added for Spicy Kill Streaks 0.6.0. The file was encoded by Unreal Engine 3, so it comes from
  an Unreal Engine 3 game such as Unreal Tournament 3 ((c) Epic Games).

flamboyant\
  The Heroes of Newerth "Flamboyant" announcer (Heroes of Newerth is (c) S2 Games / Frostburn
  Studios), taken from the MegaKill Announcer addon by Robison Karls Custodio
  (github.com/robisonkarls/MegaKill_Announcer), which ships them as "used under fair use for a
  personal addon". Converted to Ogg Vorbis and renamed to match the other packs.

sexy\firstblood.ogg
  From the HKSounds addon (github.com/ErnestasBaltinas/hksounds), whose "UT Classic (Female)"
  pack is the same recordings as our sexy pack. Converted to mono Ogg Vorbis.

triplekill.ogg (male)
  From MegaKill Announcer's Unreal Tournament pack (the same announcer as the male pack;
  Unreal Tournament is (c) Epic Games). Converted to Ogg Vorbis and raised to the same level.

Getting ganked (all packs but flamboyant)
  Not a file in the addon: it plays the game's own sound/creature/peon/peonpissed4.ogg (the Peon's
  "Me not that kind of orc!", (c) Blizzard Entertainment) by its file ID.

Retribution, now and then (all packs)
  Not a file in the addon: it plays one of the game's own creature voice lines (file ID 5769482,
  (c) Blizzard Entertainment). (What it says is a surprise.)

A kill after dying 3+ times in a row (all packs)
  Not a file in the addon: it plays one of the game's own creature voice lines (file ID 995083,
  (c) Blizzard Entertainment). (What it says is a surprise.)

Kudos (all packs)
  Not files in the addon: they play the game's own character /cheer voices
  (sound/character/<race>/...cheer01/02.ogg), sound/interface/ui_legendary_item_toast.ogg,
  sound/interface/ui_80_azeriteloot_toast.ogg and sound/spells/shadowwordpain_chest.ogg
  ((c) Blizzard Entertainment) by their file IDs.

quiet\
  The same recordings as above at 75% volume (made by tools/make_quiet.sh), played for friends'
  kills and deaths. Same sources and owners as the originals.

custom\
  Your own files. Nothing ships there.
